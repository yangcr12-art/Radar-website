# 球员内置规则分析 v3

Goal: 在球员数据页根据当前球员、勾选指标及百分位模式生成可追溯文字，不接外部 AI。

DoD: 生成入口可用；证据可展开；更换输入后报告失效；原始数据及雷达口径不变；规则与回退有测试。

Scope: 仅分析已导入的数据。无抓取、无综合能力评级、无战术适配或伤病推断。质量级别 Research。

## 输入与比较口径

读取球员详情的原字段、原值、标准/算法百分位、算法配置，以及每列有效记录数与是否存在差异。报告比较群体为该数据集首个登记位置相同的球员，各指标按此群体的有效记录重算，包含自身。不受搜索关键词或指标勾选影响。Position按逗号（含中文逗号）、斜线、分号拆分，去空格、转大写后，首项精确匹配；不自动合并左右侧或相近位置。缺位置时拒绝报告，不回退全数据集。不是跨联赛或全球排名。后端新增 `comparisonCount`、`comparisonHasVariation` 是证据元数据，不改变排名或百分位计算。

标准百分位使用原有并列中位分布位置；算法模式使用原有平滑/稀疏事件评分，不能将其解释为超过相同比例的球员。报告与雷达共享模式选择，但比较群体不同，数值可能不同；既有数据表、雷达和散点图不重算。

## 文本规则

- ≥90 高位；[65,90) 较高；(35,65) 中间；(10,35] 较低；≤10 低位。阈值是产品规则，未经预测效果校准。
- 已知非门将位置不评价门将专属指标；位置未知不猜测。正文采用球员概述、主要特点与优势、需要关注的方面、其他表现四部分，以主题段落呈现；原字段与算法放在折叠的数据依据中。数量与成功率两项均被勾选且方向一致时生成联合判断。
- 不把高位全部称为“优势”：次数类只描述参与量，效率类描述成功率，结果类描述产出；未知字段仅保留证据，不进入能力段落。
- 只对明确登记的英文原字段使用足球语义；别名未登记时保守回退。字段的反向配置与预期不符时只描述分布。
- 不参与评分及年龄等背景字段不作能力评价；缺原值、缺评分、非数值、越界评分跳过。
- 比较人数未知或少于8、全体同值时不生成结论。8–29条提醒小群体波动。
- 出场分钟不足900提醒累计样本有限。分钟未知则明确缺失。900不是稳定性保证；效率的尝试次数未纳入，统一提醒该边界。
- 球队/位置/年龄/分钟仅从原字段描述，不推测缺失资料。

## 中文叙述规则（v2）

参考用户提供英文样例的组织方式，将同一足球主题下相关数据组织成段落；不复制样例中的全球排名、战术适配或无证据的因果断言；同位置说法由单独的报告比较群体支持。中文正文保留关键原值与分布位置，证据表保留完整英文原字段。

主题包括机会创造、射门与进球、向前输送、持球突破、传中、传球参与、空中争夺、防守与进攻对抗、扑救、失球环境、球权丢失、犯规与纪律。采用显式原字段目录，方向不匹配的字段不进入主题；主题内规范化同名字段只取首项作为叙述依据，完整原字段仍保留在证据表。

联合规则：高参与+低成功率进入观察重点；低参与+高成功率进入其他表现并指出参与量与效率不同；双高作为积极信号；高参与+中间效率只肯定参与特征。门将/反向字段仍沿用证据筛选规则。辅助指标有相反低位表现时单独补充观察段落，不丢弃反证。

非配对主题将最多三个相关高位或低位指标串联到一段。正文最多三段特点、三段关注、两段其他；优先关联证据较多的段落，再按最偏离50的指标排序，只用于编辑重点，不是球员评分。所有可用字段继续在证据表呈现。未知字段单独保留证据；无已知主题时明确资料不足，不拼出泛泛的球员画像。

概述按原始年龄、球队、位置、惯用脚、身高、分钟生成；只翻译登记的已知位置简称，不猜测主次位置、国籍、国家队身份、联赛或年份。身高缺少单位时不补造单位。出场≥900分钟只称已有一定比赛积累，不称结论可靠。

## 交互与失效

点击生成后读取一次 `/api/player-data/player/<id>?datasetId=<id>&comparison=position`，后端在内存中筛选、重算，不写回数据集；返回比较位置与人数元数据。浏览器内组织报告文字，零外部 AI 请求。请求期间禁用重复生成，切换输入或离开页面后忽略迟到响应。球员、数据集、数据版本、字段证据、勾选或模式变化即隐藏旧报告并要求重新生成。加载及错误期间禁用生成；球员/数据集与详情不一致时禁用。离开页面后不保留报告，不在本地或服务器保存分析文本。

## v2 行为不变性清单

- 入口、选择球员、勾选指标及百分位切换保留；变化仅是报告叙述与呈现。
- 核心页面导入、导出、预设及雷达生成均无业务修改。
- 原有表格/雷达的有效人数、标准/算法百分位、value/per90语义不变；v3报告独立使用同位置群体。
- 加载门禁、身份校验、切换后失效及不保存报告的行为不变。


## v3 语言与同位置比较

按用户提供的英文样例使用直接的足球语言：先说球员特点，再接相关数据和具体问题。去掉“提供依据、共同支持、画像、区分技术执行”等模板连接句。标准百分位正文可以描述相对同位置球员的高低；算法模式改称同位置算法评分较高/较低，不将算法分数误写成实际超过比例。计数和成功率分别解释，低参与不直接判成能力不足。反向字段高评分对应事件少，不能写成原始值较多。

新增后端 `player_position_comparison.py` 及可选查询参数；参数缺省保留原行为。原数据深拷贝后重算，缺位置不猜测。生成入口每次额外发出一次只读详情请求，不轮询；位置群体不足8时沿用小样本门禁。
